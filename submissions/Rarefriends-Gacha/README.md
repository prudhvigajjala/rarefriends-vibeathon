# Rarefriends-Gacha

This is a submission for the Rare Friends Vibeathon.

## Game Details
Rarefriends-Gacha is a chance-based collection game where players use gacha mechanics to collect rare friends.

## SDK Version
Built with FriendSDK v0.1.2

## Run Instructions
To run this game locally, execute the following command from the root folder:

npm run dev:game -- games/Rarefriends-Gacha
